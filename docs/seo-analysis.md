# SEO-анализ сайта betonicum.ru

**Дата:** июнь 2026
**Метод:** кабинетный анализ по данным поисковой индексации и конкурентной выдачи.

> **Ограничения исследования.**
> 1. Прямой доступ к сайту из среды анализа заблокирован — robots.txt, sitemap.xml, скорость
>    загрузки, разметку schema.org и содержимое страниц напрямую проверить нельзя; такие пункты
>    помечены **[проверить]**.
> 2. Поисковая выдача анализировалась через англоязычный индекс (аналог Google);
>    **позиции в Яндексе могут отличаться** — для рынка промышленных полов РФ Яндекс является
>    основным источником трафика, поэтому выводы о видимости нужно перепроверить в
>    Яндекс.Вебмастере и сервисах типа Topvisor/Keys.so.

Итого в индексе видно **~14 страниц**. Для производителя с восемью продуктами, кейсами с 2001

### Проблемы индексации

1. **Посторонний PDF в индексе** — кроме риска компрометации (см. UX-исследование, п. 4.1),
   это прямой SEO-вред: страница нерелевантной тематики размывает тематический профиль хоста.
   Действия: удалить файл, отдать 410, убрать из индекса через Яндекс.Вебмастер / GSC,
   проверить uploads на другие посторонние файлы.
2. **`/tyutyutyu/`** — тестовый слаг в индексе. Переименовать в осмысленный URL +
   301-редирект.
3. **Кейсов в индексе один**, статей блога — одна. Либо контента реально мало, либо он
   закрыт от индексации / не перелинкован. **[проверить]** наличие sitemap.xml и его полноту.

## 2. On-page: мета-теги и структура

### Title — главная системная проблема

Все страницы используют шаблон «{Название} — Полиуретан цементные полы, покрытия | Betonicum»:

- Карточки не дифференцированы: «Resalux SL», «Resalux SL 12», «Resalux SL 23» для поисковика
  и пользователя в выдаче почти неразличимы;
- Ни в одном title нет коммерческих модификаторов («купить», «цена», «от производителя»),
  которые есть у всех конкурентов в топе;
- Слово «Главная» в title главной страницы — потерянное место в самом ценном теге сайта.

**Рекомендуемые шаблоны:**

| Страница | Title |
|---|---|
| Главная | `Полиуретан-цементные полы Resalux от производителя — Betonicum` |
| Карточка | `Resalux TG — противоскользящее полиуретан-цементное покрытие для пищевых производств \| цена от производителя` |
| Каталог | `Полиуретан-цементные покрытия Resalux: каталог систем от производителя` |
| Кейс | `Полы для мясоперерабатывающего цеха — объект «Стародворские колбасы» (ABI PRODUCT)` |

### Прочее on-page **[проверить на живом сайте]**

- H1 на карточках: должен описывать продукт и его назначение, а не повторять «Resalux SL»;
- Уникальные meta description с УТП (производитель, с 2001 г., «пол за один день»);
- Alt-тексты фотографий объектов (это потенциальный трафик из поиска по картинкам);
- Хлебные крошки + разметка `BreadcrumbList`.

### Структурированные данные (почти наверняка отсутствуют — **[проверить]**)

- `Organization` (+ `logo`, `contactPoint`) — на всём сайте;
- `Product` с `brand: Resalux`, `offers` (хотя бы `priceCurrency` + «по запросу») — на карточках;
- `FAQPage` — на карточки и посадочные (вопросы про расход, сроки, температуру эксплуатации);
- `Article` — на статьи блога.

## 3. Видимость в поиске и конкуренты

### Брендовые запросы — хорошо

По запросу «Resalux полы» выдача почти полностью принадлежит betonicum.ru (6+ позиций из 10),
плюс карточка на stroyportal.ru и страница дилера infloors.ru. Бренд-SERP здоровый.
Отдельная находка: страница дилера на infloors.ru имеет title **«Пустой шаблон»** — стоит
попросить партнёра поправить, это витрина бренда.

### Коммерческие запросы — сайта нет в топ-10

По двум главным деньгоносным запросам betonicum.ru **отсутствует в первой десятке**:

**«полиуретан-цементные полы купить производитель»** — в топе: politaks.ru, teohim.ru
(Элакор-ПЦ), market-parket.ru, praspan.ru, esp.ru, lkmpolymer.ru, astra-chemie.ru, silikal.ru,
akatech.ru.

**«промышленные полы для пищевого производства»** — в топе: uteh.ru, beton-krasko.ru,
polimer-pol.com, politaks.ru, cmt-product.ru, tpmstroi.ru, polimer-s-group.ru.

### Чем выигрывают конкуренты (видно прямо из выдачи)

| Приём конкурентов | Пример | Есть у Betonicum? |
|---|---|---|
| Цена в title/сниппете | «…от 4 968 руб./м² под ключ» (esp.ru), «от 7 980 руб.» (lkmpolymer.ru) | Нет |
| Отраслевые посадочные | politaks.ru/prompol/piwevoj-pol/, beton-krasko.ru/catalog/pishchevie_proizvodstva/ | Нет — отраслей нет в структуре URL |
| Сегментация «мясокомбинаты, пивоварни, молочные заводы…» прямо в meta | beton-krasko.ru | Частично в тексте главной |
| Информационные статьи под проблемные запросы | uteh.ru/article/…, cmt-product.ru/blog/… | 1 статья |

Вывод: Betonicum конкурирует контентом из ~14 страниц против сайтов с развитой структурой
«продукт × отрасль × проблема». Это главная причина отсутствия в топе.

## 4. Семантическое ядро (каркас)

### Кластер 1 — продуктовый (карточки + каталог)
- полиуретан-цементные полы / покрытия / наливные полы (+ купить, цена, производитель, за м²)
- антистатический наливной пол (SL AS), термостойкое покрытие пола (RT),
  противоскользящее покрытие (TG/SR), ремонт промышленных полов (RC)

### Кластер 2 — отраслевой (новые посадочные, самый высокий приоритет)
- полы для пищевого производства / мясокомбината / колбасного цеха / молочного завода /
  пивоварни / птицефабрики / рыбного цеха / пекарни / фармпроизводства / химического
  производства / морозильных камер
- Каждая страница: проблематика отрасли → требуемые свойства → рекомендованные системы
  Resalux → кейс этой отрасли → форма запроса. Структура URL: `/resheniya/pishchevoe-proizvodstvo/`.

### Кластер 3 — информационный (блог, средний приоритет)
- «полиуретан-цементный пол или эпоксидный: что выбрать», «требования к полам ХАССП»,
  «расход полиуретан-цементного покрытия на м²», «пол за один день» (уже есть — развить),
  «температура эксплуатации полимерных полов», «полы для мойки горячей водой»

### Кластер 4 — B2B-специфика
- ТДС/технологические регламенты (запросы проектировщиков «узлы примыкания полимерного пола»,
  «спецификация полиуретан-цементного пола») — центр документации из UX-исследования
  закрывает и этот кластер.

Видимые упоминания: stroyportal.ru (карточка продукции), infloors.ru (дилер),
betonicum-stroy.fis.ru (профиль на FIS). Профиль минимальный. **[проверить]** полный список
через Яндекс.Вебмастер / Ahrefs.

Рекомендации:
- Зарегистрировать/актуализировать карточки в отраслевых каталогах (beton.ru, stroyportal,
  Pulscen, Satom) с единым NAP;
- Кейсы с упоминаемыми клиентами (ABI PRODUCT) — повод для публикаций в отраслевых СМИ

- Страница «О компании»: реквизиты, история с 2001 г., сертификаты, фото производства —
  сигналы E-E-A-T для коммерческой выдачи.

## 6. Локальное SEO и региональность

Сигналы противоречивы: юр. адрес — Иваново, телефон — код 495 (Москва), в контенте
упоминаются офисы во Владимирской и Московской областях. Для Яндекса региональность —
ранжирующий фактор.

- Завести/подтвердить **Яндекс Бизнес** на каждый реальный офис (Москва, Владимир, Иваново);
- Указать регионы в Яндекс.Вебмастере;
- На странице контактов — все адреса с картой и разметкой `Organization`/`LocalBusiness`;
- Добавить 8-800 или региональные номера, если география продаж — вся РФ.

## 7. Технический SEO — чек-лист для проверки на живом сайте

Так как прямой доступ отсутствовал, эти пункты — обязательная программа аудита первым шагом:

- [ ] HTTPS + редирект с http и с www (или на www — единое зеркало);
- [ ] robots.txt: не закрыт ли блог/кейсы; закрыты ли служебные `/wp-json/`, параметры;
- [ ] sitemap.xml: существует, полный, подключён в Вебмастер/GSC;
- [ ] Скорость и Core Web Vitals (LCP < 2,5 с; WordPress без оптимизации обычно проваливает) —
  внедрение PWA-слоя из `docs/pwa-implementation.md` напрямую улучшает повторные загрузки,
  но для первой загрузки нужны: сжатие изображений (WebP), кэш-заголовки, lazy-load;
- [ ] Дубли: `?replytocom`, пагинация, attachment-страницы WP (`/attachment/`) — закрыть;
- [ ] 404/501 на старых URL после исправления слагов — настроить 301;
- [ ] Безопасность: аудит uploads и ядра WP (посторонний PDF — возможный признак взлома;
  взломанные сайты Яндекс помечает и пессимизирует).
