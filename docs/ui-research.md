# UI-исследование betonicum.ru

**Дата:** июнь 2026
**Цель:** оценить визуальный интерфейс текущего сайта и сформировать основу для дизайн-системы.
**Связано:** [design-system.md](design-system.md) · [ux-research.md](ux-research.md) ·
[market-research-and-conversion-structure.md](market-research-and-conversion-structure.md)

> **Ограничение (важно).** Прямой визуальный доступ к betonicum.ru из среды анализа **заблокирован**
> сетевой политикой (ответ `403 host_not_allowed` на всех попытках). Поэтому реальные цвета, шрифты,
> сетка и состояния интерфейса вживую **не наблюдались**. UI-аудит ниже построен на:
> 1) косвенных признаках (платформа WordPress, тема, структура URL и PDF-спецификаций 2020 г.);
> 2) отраслевых визуальных конвенциях производителей промышленных полов;
> 3) выводах из проведённых UX/SEO-исследований.
> Пункты, требующие проверки на живом сайте, помечены **[проверить]**. Соответственно, дизайн-система
> в [design-system.md](design-system.md) — это **проектируемый эталон** для бренда Betonicum/Resalux,
> а не реверс существующего гайдлайна.

## 1. Что известно о текущем UI (косвенно)

| Признак | Источник | Вывод для UI |
|---|---|---|
| Сайт на **WordPress** | `/wp-content/...` в индексе | Вероятна готовая/слегка кастомизированная тема; типовые паттерны WP |
| PDF-спецификации помечены **«© 2020 г.»** | имена файлов в индексе | Визуальный язык, скорее всего, не обновлялся с ~2020 — устаревает **[проверить]** |
| Title на всех страницах однотипные | SEO-анализ | Шаблонность → вероятно, и в UI слабая дифференциация страниц **[проверить]** |
| Каталог построен «от номенклатуры» (SL/TG/SR…) | UX-исследование | Навигация и карточки, вероятно, не отражают задачи клиента |
| Бренд: тёмный «промышленный» характер, продукт Resalux | материалы, видео укладки | Уместна индустриальная палитра (бетон + акцент) |

## 2. Гипотезы по типичным UI-проблемам (для проверки на сайте)

Характерные слабости WordPress-сайтов производителей в этой нише — чек-лист для живого аудита:

1. **Слабая визуальная иерархия первого экрана [проверить].** Часто: общий баннер-слайдер без
   конкретного УТП и без явного CTA. → Нужен Hero с одним оффером и одной главной кнопкой.
2. **Карточки систем без визуального кода [проверить].** Названия SL/TG/SR выглядят одинаково.
   → Цветовые «свотчи», теги назначения, единая сетка карточек.
3. **Нет единой системы кнопок [проверить].** В WP-темах CTA часто разнородны (цвет/размер/форма).
   → Один компонент кнопки с вариантами (primary/dark/ghost).
4. **Перегруженный или, наоборот, пустой первый экран.** → Баланс: оффер + факты доверия + форма.
5. **Типографика темы по умолчанию.** → Единая шкала и один шрифт с понятными весами.
6. **Слабые состояния форм и доверительные блоки.** → Явные фокус-состояния, короткая форма,
   видимые сигналы доверия (с 2001, контроль качества, гарантия).
7. **Адаптив «из коробки».** Telephone не всегда `tel:`, меню-бургер неудобен. → Mobile-first ревизия.

## 3. Бенчмарк визуального языка конкурентов

| Конкурент | Визуальный приём | Берём в дизайн-систему? |
|---|---|---|
| ТЭОХИМ / Элакор | Плотный, «каталожный», много цифр доверия | Цифры доверия — да; плотность — нет (делаем воздушнее) |
| ЕСП Полимер | Корпоративный, блок «контроль качества» | Блок доверия — да |
| Монтажники (tpmstroi и пр.) | Крупные цены и CTA на первом экране | Явный ценовой/CTA-акцент — да |

Вывод: рынок визуально консервативен и «каталожен». **Возможность отстройки** — чистый, современный,
воздушный индустриальный UI с сильной типографикой и единым акцентом. Это поддерживает
эстетико-юзабилити эффект (красивее → воспринимается надёжнее).

## 4. Принципы будущего UI (требования к дизайн-системе)

1. **Индустриальный, но не «грязный».** Тёмно-синий (инженерия, доверие) + оранжевый акцент
   (стройка, энергия, CTA) + бетонно-серые нейтрали.
2. **Один акцентный цвет = один смысл.** Оранжевый только для действий и ключевых выделений
   (эффект Ван Ресторфа). Не «раскрашивать» им всё подряд.
3. **Сильная типографическая иерархия.** Крупные заголовки, чёткая шкала, один гротеск (Manrope).
4. **Карточки и сетка как основа.** 12-колоночная сетка, единый радиус и тени, повторяемые компоненты.
5. **Mobile-first и быстрый отклик.** Связь с порогом Доэрти и PWA (см. [pwa-implementation.md](pwa-implementation.md)).
6. **Доступность.** Контраст текста ≥ 4.5:1, видимый фокус, кликабельный телефон, размер целей ≥ 44px.
