# Дизайн-система Betonicum

**Дата:** июнь 2026
**Статус:** проектируемый эталон для бренда Betonicum / Resalux (см. ограничение в [ui-research.md](ui-research.md)).
**Источник истины (код):** [`site/styles.css`](../site/styles.css) — все токены заданы как CSS-переменные.
**Применение:** первая страница [`site/index.html`](../site/index.html).

Дизайн-система описывает визуальный язык индустриального B2B-бренда: надёжность (инженерия),
энергия (стройка/действие) и чистота (современный воздушный интерфейс как отстройка от
«каталожных» конкурентов).

---

## 1. Принципы

1. **Один акцент — один смысл.** Оранжевый = действие и ключевые выделения (эффект Ван Ресторфа).
2. **Иерархия через типографику и пространство**, а не через множество цветов.
3. **Повторяемые компоненты** на 12-колоночной сетке — предсказуемость (закон Якоба).
4. **Mobile-first, доступность, скорость** (контраст ≥ 4.5:1, цели ≥ 44px, отклик < 400 мс).

## 3. Типографика

**Шрифт:** Manrope (гротеск, хорошая читаемость в B2B), fallback — `system-ui`.

| Роль | Токен | Размер / интерлиньяж | Вес |
|---|---|---|---|
| Display (Hero H1) | `--fs-display` | 52 / 1.08 | 800 |
| H1 | `--fs-h1` | 40 / 1.12 | 800 |
| H2 | `--fs-h2` | 30 / 1.18 | 800 |
| H3 | `--fs-h3` | 22 / 1.25 | 800 |
| Lead (подзаголовок) | `--fs-lead` | 18 / 1.5 | 400–500 |
| Body | `--fs-body` | 16 / 1.55 | 400 |
| Small | `--fs-small` | 14 / 1.45 | 400–600 |
| Caption / Overline | `--fs-cap` | 12 / 1.4 | 700, uppercase, tracking .14em |

Заголовки — с отрицательным трекингом (`-.01em`) для плотности. Overline (надзаголовок) — оранжевый,
капсом: задаёт ритм секций.

На мобильных Display/H1/H2 уменьшаются через переопределение токенов в медиа-запросе.

---

## 4. Сетка, отступы, радиусы, тени

- **Контейнер:** `--container: 1200px`, боковые поля `--gutter: 24px`.
- **Сетка:** 12 колонок, основные раскладки — `grid-template-columns` (hero 1.15/.85, системы 3, отрасли 6).
- **Шкала отступов (4-point):** `--sp-1…9` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px.
  Вертикальный ритм секций — `--sp-9` (96px), на мобайле — 56px.
- **Радиусы:** `--r-sm 8` · `--r-md 12` · `--r-lg 16` · `--r-xl 24` · `--r-pill 999`.
- **Тени:** `--sh-sm` (карточки) · `--sh-md` (hover) · `--sh-lg` (плавающая форma в hero).

**Брейкпоинты:** ≤992px (планшет: hero в одну колонку, меню скрыто), ≤560px (мобайл: всё в одну колонку).

## 6. Логотип-марка

Знак — три «слоя пола» (светлый / оранжевый / светлый) на navy-плашке (SVG в шапке/футере и иконках
PWA). Отражает суть продукта — слоистое полимерное покрытие. В футере используется на более светлом
`--c-primary-700` для контраста с тёмным фоном.

## 9. Доступность и контраст (WCAG 2.1 AA)

Целевой минимум: обычный текст ≥ 4.5:1, крупный (≥24px/19px bold) и UI ≥ 3:1.

| Пара (текст / фон) | Контраст | Статус |
|---|---|---|
| `ink #1c2733` / `surface #fff` | ~13.8:1 | ✅ AAA |
| `ink #1c2733` / `canvas #eef1f5` | ~12:1 | ✅ AAA |
| `muted #5a6b7d` / `surface #fff` | ~5.3:1 | ✅ AA |
| `#fff` / `primary-800 #16314f` | ~11:1 | ✅ AAA |
| `#fff` / `accent-500 #f08c26` (кнопка) | ~2.4:1 | ⚠️ только для крупного/bold текста кнопок |
| `accent-700 #c2701a` / `surface #fff` (текст-ссылка) | ~3.9:1 | ⚠️ для крупного/полужирного |
| `faint #8294a6` / `surface #fff` | ~3.1:1 | только подписи/декор, не для body |

**Правила:** (1) оранжевый — для **крупного/жирного** текста кнопок и UI-элементов, не для абзацев;
для акцентной ссылки в тексте использовать `accent-700` полужирным. (2) `faint` — только подписи.
(3) Фокус виден всегда: `:focus-visible` → оранжевое кольцо `--focus-ring`.
(4) `prefers-reduced-motion` отключает анимации.

## 11. Motion-токены

| Токен | Значение | Применение |
|---|---|---|
| `--dur-fast` | 120ms | микро (hover-цвет) |
| `--dur-base` | 180ms | стандарт (кнопки, карточки) |
| `--dur-slow` | 320ms | крупные/оверлеи |
| `--ease-out` | cubic-bezier(.2,.7,.3,1) | появление, основной |
| `--ease-in` | cubic-bezier(.5,0,.8,.4) | исчезновение |

Принцип: анимируем `transform`/`opacity`/`box-shadow` (дёшево для GPU); уважаем reduced-motion.

## 12. Z-index и elevation

| Слой | Токен | z |
|---|---|---|
| База | `--z-base` | 0 |
| Поднятый (hover-карточка) | `--z-raised` | 10 |
| Sticky-хедер | `--z-sticky` | 100 |
| Оверлей/бэкдроп | `--z-overlay` | 800 |
| Модальное окно | `--z-modal` | 900 |
| Тост/тултип | `--z-toast` | 1000 |

Elevation = высота через тени: `--e-1` (sm, карточки) · `--e-2` (md, hover/выпадашки) ·
`--e-3` (lg, плавающая форма/модалки).

## 13. Иконография и изображения

- Иконки — линейные, 20–24px, `currentColor` (наследуют цвет контейнера), штрих ≈2px.
- Фото объектов — реальные, с затемняющим градиентом для контраста подписей; обязателен `alt`.
- Логотип-марка — три «слоя пола» (светлый/оранжевый/светлый) на navy-плашке; защитное поле
  вокруг знака ≥ высоте одного «слоя»; на тёмном фоне — плашка `primary-700` для контраста.

## 14. Плотность и сетка данных

Для ТДС и характеристик — компонент `.spec` (таблица): высота строки `--row-h: 44px`,
hover-подсветка строки, «шапка» на `primary-050`. Первый столбец — `muted` (параметр),
значения — `ink`.

**Бриф заказчика:** фон — пастельный тёмно-синий и серый; акцент — коралловый; в кнопках —
иконки и анимация; шрифт везде Inter; заголовки капслоком.

Реализовано слоем «DESIGN SYSTEM v3 — RESTYLE» в конце [`site/styles.css`](../site/styles.css):
переопределены **значения** токенов (имена сохранены — обратная совместимость) и добавлены оверрайды
там, где цвета были захардкожены под светлую тему. Рендеры:
[hero](screenshots/home-desktop-hero.png) · [десктоп](screenshots/home-desktop-full.png) ·
[мобайл](screenshots/home-mobile-full.png) · [styleguide v3](screenshots/design-system-v3.png).

| Приподнятая подложка | `--c-primary-100` | `#3a4865` | теги, иконки, шапки таблиц |

серый (`concrete`) для ритма секций.

## Типографика (v3)

- **Шрифт:** `Inter` на всём сайте (fallback `system-ui`). Подключение — Google Fonts в `<head>`.
- **Заголовки h1–h4 и `.title` — КАПСЛОК** (`text-transform: uppercase`, трекинг `.005em`).
  Body/lead/overline — без изменений (overline и так капсом).

## Кнопки: иконки + анимация (v3)

- Иконка внутри кнопки — класс `.btn__ic` (18×18, наследует `currentColor`).
  - `.btn__ic--arrow` — стрелка **уезжает вправо** на hover (`translateX`).
  - `.btn__ic--spin` — иконка **поворачивается** на hover.
- `.btn--primary` — по кнопке **пробегает световой блик** (псевдоэлемент `::before`), на hover —
  подъём (`translateY(-2px)`) и усиление коралловой тени.
- Все анимации на `transform/opacity` (GPU-дёшево) и уважают `prefers-reduced-motion`.

## Доступность (v3, пересчёт)

Тёмная тема улучшает контраст текста: `ink #eef2f8` на `canvas #2a3650` ≈ **11:1** (AAA),
на `surface #323f5a` ≈ 9:1 (AAA). Коралл `#ff6f5e` с белым текстом кнопки ≈ 2.6:1 — как и с
прежним оранжевым, допустимо только для **крупного/жирного** лейбла кнопки; для акцентного текста
на тёмном использовать `--c-accent-700 #ff8d7f` (≈ 4.6:1 на canvas — AA). Фокус-кольцо — коралловое.
