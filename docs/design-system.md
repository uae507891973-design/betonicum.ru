# Дизайн-система Betonicum

**Дата:** июнь 2026
**Статус:** проектируемый эталон для бренда Betonicum / Resalux (см. ограничение в [ui-research.md](ui-research.md)).
**Источник истины (код):** [`site/styles.css`](../site/styles.css) — все токены заданы как CSS-переменные.
**Применение:** первая страница [`site/index.html`](../site/index.html).

Дизайн-система описывает визуальный язык индустриального B2B-бренда: надёжность (инженерия),
энергия (стройка/действие) и чистота (современный воздушный интерфейс как отстройка от
«каталожных» конкурентов).

---

## 1. Принципы

1. **Один акцент — один смысл.** Оранжевый = действие и ключевые выделения (эффект Ван Ресторфа).
2. **Иерархия через типографику и пространство**, а не через множество цветов.
3. **Повторяемые компоненты** на 12-колоночной сетке — предсказуемость (закон Якоба).
4. **Mobile-first, доступность, скорость** (контраст ≥ 4.5:1, цели ≥ 44px, отклик < 400 мс).

## 3. Типографика

**Шрифт:** Manrope (гротеск, хорошая читаемость в B2B), fallback — `system-ui`.

| Роль | Токен | Размер / интерлиньяж | Вес |
|---|---|---|---|
| Display (Hero H1) | `--fs-display` | 52 / 1.08 | 800 |
| H1 | `--fs-h1` | 40 / 1.12 | 800 |
| H2 | `--fs-h2` | 30 / 1.18 | 800 |
| H3 | `--fs-h3` | 22 / 1.25 | 800 |
| Lead (подзаголовок) | `--fs-lead` | 18 / 1.5 | 400–500 |
| Body | `--fs-body` | 16 / 1.55 | 400 |
| Small | `--fs-small` | 14 / 1.45 | 400–600 |
| Caption / Overline | `--fs-cap` | 12 / 1.4 | 700, uppercase, tracking .14em |

Заголовки — с отрицательным трекингом (`-.01em`) для плотности. Overline (надзаголовок) — оранжевый,
капсом: задаёт ритм секций.

На мобильных Display/H1/H2 уменьшаются через переопределение токенов в медиа-запросе.

---

## 4. Сетка, отступы, радиусы, тени

- **Контейнер:** `--container: 1200px`, боковые поля `--gutter: 24px`.
- **Сетка:** 12 колонок, основные раскладки — `grid-template-columns` (hero 1.15/.85, системы 3, отрасли 6).
- **Шкала отступов (4-point):** `--sp-1…9` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px.
  Вертикальный ритм секций — `--sp-9` (96px), на мобайле — 56px.
- **Радиусы:** `--r-sm 8` · `--r-md 12` · `--r-lg 16` · `--r-xl 24` · `--r-pill 999`.
- **Тени:** `--sh-sm` (карточки) · `--sh-md` (hover) · `--sh-lg` (плавающая форma в hero).

**Брейкпоинты:** ≤992px (планшет: hero в одну колонку, меню скрыто), ≤560px (мобайл: всё в одну колонку).

## 5. Компоненты

| Компонент | Класс | Варианты / правила |
|---|---|---|
| **Кнопка** | `.btn` | `--primary` (оранж, главный CTA), `--dark` (navy), `--ghost`, `--ghost-light` (на тёмном), `--lg`, `--block`. На странице — **один** primary-CTA в зоне видимости (Ван Ресторф) |
| **Чип** | `.chip` | Фильтры, быстрые ссылки; pill-форма |
| **Тег** | `.tag` / `.tag--accent` | Свойства систем, метки разделов |
| **Карточка** | `.card` / `.card--hover` | Базовый контейнер; hover-подъём для кликабельных |
| **Поле** | `.field` | Единый стиль input; видимый фокус (navy-бордер) |
| **Секция** | `.section` + `--concrete` / `--ink` / `--tight` | Чередование фонов задаёт ритм и группировку (гештальт) |
| **Надзаголовок** | `.overline` | Оранжевый капс над H2 |

Прикладные блоки (на токенах): `.hero`, `.trust`, `.wizard`, `.sys`, `.compare`, `.oneday`,
`.ind`, `.case`, `.duo`, `.faq`, `.cta-band`, `.footer`.

## 6. Логотип-марка

Знак — три «слоя пола» (светлый / оранжевый / светлый) на navy-плашке (SVG в шапке/футере и иконках
PWA). Отражает суть продукта — слоистое полимерное покрытие. В футере используется на более светлом
`--c-primary-700` для контраста с тёмным фоном.

---

## 7. Как UI-законы зашиты в систему

| Закон / эффект | Реализация в системе |
|---|---|
| Ван Ресторф | Единственный оранжевый `--primary`-CTA выделяется на фоне нейтралей |
| Якоб | Стандартная раскладка header/hero/секции, привычные паттерны |
| Фиттс | Кнопки 44px+, `tel:`-телефон, крупные кликабельные карточки |
| Миллер | Лента доверия — 5 пунктов; меню — 5 пунктов |
| Гештальт (близость / общая зона) | Чередование фонов секций, группировка карточек |
| Эстетика-юзабилити | Единый воздушный стиль, качественная типографика |
| Доступность | Контраст, фокус-состояния, размеры целей |
