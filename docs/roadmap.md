# Дорожная карта развития сайта betonicum.ru

**Дата:** июнь 2026
**Позиционирование:** производитель материалов Resalux (B2B: подрядчики, дилеры, проектировщики, снабженцы).
**Синтез документов:** [ux-research.md](ux-research.md) · [seo-analysis.md](seo-analysis.md) ·
[market-research-and-conversion-structure.md](market-research-and-conversion-structure.md) ·
[improvements.md](improvements.md) · [pwa-implementation.md](pwa-implementation.md) · [cjm.md](cjm.md)

Карта связывает все исследования в один поэтапный план: что, в каком порядке, с какими
зависимостями и метриками. Логика порядка: **сначала фундамент и доверие** (без них остальное не
конвертирует), **затем ядро конверсии**, **затем масштабирование канала сбыта**.

---

## Обзор фаз

| Фаза | Название | Срок | Цель | Соответствие |
|---|---|---|---|---|
| **0** | Фундамент и безопасность | 1–2 нед | Убрать риски, подготовить почву | improvements §5 |
| **1** | Доверие и быстрые победы | 2–4 нед | Закрыть разрыв с лидерами, снять барьеры | improvements §1, Вариант A |
| **2** | Ядро конверсии | 1–2 мес | Инструменты, которых нет у конкурентов | improvements §3, §2, Вариант B |
| **3** | Контент и SEO-охват | парал. с 2–3 | Трафик из отраслевых запросов | seo §4, improvements §2 |
| **4** | Канал сбыта и удержание | 3–4 мес | Масштабирование под модель «производитель» | improvements §4, Вариант C |

Фазы 0–1 строго последовательны. Фазы 2 и 3 идут параллельно. Фаза 4 стартует после стабилизации 2.

---

## Фаза 0 — Фундамент и безопасность (1–2 недели)

**Цель:** устранить риски и технический долг, иначе любые улучшения сверху ненадёжны.

| Задача | Зависит от | Результат / DoD |
|---|---|---|
| Аудит безопасности WP, чистка `uploads` (посторонний PDF), смена паролей | — | Чистая медиабиблиотека, нет посторонних файлов в индексе |
| Резервное копирование + staging-окружение | — | Есть где тестировать без риска для прод |
| HTTPS, единое зеркало (www / без www), карта `sitemap.xml`, `robots.txt` | — | Корректная индексация, подключён Вебмастер/GSC |
| Исправление слага кейса `/tyutyutyu/` + 301 | — | Осмысленные URL объектов |

**Веха 0:** сайт безопасен, корректно индексируется, есть staging.
**Блокеры:** доступ к хостингу/WP-админке.

---

## Фаза 1 — Доверие и быстрые победы (2–4 недели)

**Цель:** закрыть главный разрыв с ТЭОХИМ/ЕСП (доверие) и снять барьеры «отвалов» (цена, мета).

| Задача | Зависит от | Результат / DoD |
|---|---|---|
| **Лента доверия** в Hero: «с 2001», производство, N млн м², N объектов, гарантия N лет | **данные от заказчика** | Факты в первом скролле |
| Блок «Контроль качества» (по образцу ЕСП) + сертификаты для пищёвки | данные/сканы | Снятие возражения «брак» |
| **Открыть цену:** прайс PDF или вилки «от» | ценовая политика | Нет барьера «цена по запросу» |
| Уникальные title / description / H1 по шаблонам | Фаза 0 | Рост CTR в выдаче |
| Sticky-CTA + мессенджеры (WhatsApp/Telegram) + `tel:` | — | Больше каналов обращений |

**Веха 1:** посетитель за один экран видит, что Betonicum — серьёзный производитель, и понимает цену.
**Блокеры (критично):** реальные цифры, сертификаты, ценовая политика — см. §«Зависимости от заказчика».

---

## Фаза 2 — Ядро конверсии (1–2 месяца)

**Цель:** дать инструменты, которых нет у конкурентов (отстройка), и довести прототип до боя.

| Задача | Зависит от | Результат / DoD |
|---|---|---|
| **Мастер подбора системы** (3 шага: отрасль → нагрузки → температура) | линейка систем, логика подбора | Подбор без знания марок, лид |
| **Калькулятор расхода** материала на м² | нормы расхода систем | Микроконверсия + квалификация |
| Доведение прототипа первого экрана до прод (`pwa/app/`) | Фаза 1 | Боевой Hero по конверсионной структуре |
| Schema.org: Organization, Product, FAQPage, BreadcrumbList | Фаза 0 | Расширенные сниппеты |
| PWA-слой (manifest + SW), Core Web Vitals | Фаза 0 | Скорость, офлайн-доступ (порог Доэрти) |
| Заявка на образец/выкрас | — | Тёплый лид |

**Веха 2:** работает мастер подбора и калькулятор; сайт быстрый и устанавливается как PWA.
**KPI:** доля прошедших мастер 25–35 %, конверсия в заявку 3–5 %.

---

## Фаза 3 — Контент и SEO-охват (параллельно фазе 2–3)

**Цель:** вырасти из «тонкого сайта» (~14 страниц) в источник отраслевого трафика.

| Задача | Зависит от | Результат / DoD |
|---|---|---|
| 6–8 **отраслевых посадочных** (мясо, молочка, напитки, фарма, склады, морозильники) | Фаза 0 (структура URL) | Вход в коммерческий топ |
| Раздел **«Объекты»** с фильтром по отраслям | согласие на публикацию кейсов | Соц. доказательство + длинный хвост |
| Сравнение систем Resalux (таблица) | линейка систем | Самостоятельный выбор |
| Статья «ПУ-цемент vs эпоксидка» + блог-кластер (ХАССП, расход, «пол за день») | — | Информационный трафик, экспертность |
| Региональность (Яндекс Бизнес, единый NAP) | адреса офисов | Локальная выдача |

**Веха 3:** 50+ страниц в индексе, топ-10 по отраслевым запросам, ×3 небрендового трафика (6 мес).

---

## Фаза 4 — Канал сбыта и удержание (3–4 месяца)

**Цель:** масштабировать продажи материала через сеть — то, что прямо вытекает из модели «производитель».

| Задача | Зависит от | Результат / DoD |
|---|---|---|
| Раздел **«Подрядчикам и дилерам»**: опт, дилерские цены, обучение, заявка на партнёрство | условия партнёрства | Канал сбыта на сайте |
| «Поддержка на объекте»: выезд технолога, регламенты, горячая линия | регламенты укладки | Лояльность укладчиков |
| **Центр документации** (ТДС/регламенты/сертификаты) + «скачать всё для объекта» + офлайн через PWA | документы | Удержание проектировщиков/подрядчиков |
| **Личный кабинет дилера** (цены, заявки, статусы) | бэкенд | LTV партнёров, push-уведомления |
| Web Push (новые материалы, статус заявки) | кабинет | Реактивация |

**Веха 4:** оформлен дилерский канал, есть кабинет и центр документации; повторные закупки растут.

## Зависимости от заказчика (критический путь)

Эти данные блокируют фазы 1 и 4. Запросить в первую очередь:

| Данные | Блокирует | Почему критично |
|---|---|---|
| Метраж объектов, число объектов, срок гарантии, ISO/сертификаты | Фаза 1 (доверие) | Фейковые цифры в B2B недопустимы; без реальных — разрыв с ТЭОХИМ/ЕСП не закрыть |
| Согласие на публикацию кейсов и логотипов | Фаза 3 (объекты) | Соц. доказательство — ключевой B2B-триггер |
| Ценовая политика (что показывать открыто) | Фаза 1 (цена) | Снятие барьера «по запросу» |
| Условия для дилеров/подрядчиков | Фаза 4 (канал) | Основа модели «производитель» |
