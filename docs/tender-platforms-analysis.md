# Анализ тендерных площадок по тематике «товарный бетон / ЖБИ»

> Цель: определить, **откуда** брать тендеры по нашей тематике (товарный бетон, бетонные смеси, ЖБИ, растворы) и **как** это технически парсить — официально, легально и с минимальными издержками.
>
> Дата подготовки: июнь 2026.

---

## 1. Наша тематика на языке классификаторов

Чтобы фильтровать тендеры на любой площадке, нужны коды-фильтры. Основной — **ОКПД2**, дополнительно **КТРУ** и **ОКВЭД2** (для отбора по виду деятельности заказчика/поставщика).

### Ключевые коды ОКПД2

| Код | Расшифровка | Приоритет |
|-----|-------------|-----------|
| `23.63` / `23.63.10.000` | Бетон, готовый для заливки (**товарный бетон**) | 🔴 основной |
| `23.61` | Изделия из бетона для строительства (**ЖБИ**) | 🔴 основной |
| `23.61.11` | Блоки и кирпичи из цемента, бетона, искусственного камня | 🟠 |
| `23.61.12` | Сборные строительные изделия из цемента, бетона | 🟠 |
| `23.61.20` | Конструкции сборные строительные из бетона | 🟠 |
| `23.64` | Смеси и растворы строительные (сухие смеси, ЦПС) | 🟠 |
| `23.69` | Прочие изделия из бетона, цемента, гипса | 🟡 смежное |
| `23.51` | Цемент | 🟡 сырьё |
| `08.12` | Гравий, песок, глины (инертные материалы) | 🟡 сырьё |
| `23.62` | Изделия из гипса для строительства | 🟡 смежное |

Дополнительно ловим тендеры по **ключевым словам** в наименовании объекта закупки: «бетон», «бетонная смесь», «БСГ», «товарный бетон», «раствор готовый», «ЖБИ», «железобетон», «плита перекрытия», «фундаментный блок (ФБС)», «бордюр», «тротуарная плитка» и т. п. — потому что заказчики часто проставляют коды неточно.

## 2. Карта источников тендеров

Источники делятся на три уровня. Парсить лучше **сверху вниз**: чем выше уровень, тем дешевле и легальнее доступ.

### Уровень 1. Первоисточник — ЕИС (zakupki.gov.ru)

**Единая информационная система в сфере закупок** — государственный первоисточник по **44-ФЗ** (госзаказчики) и **223-ФЗ** (госкорпорации, субъекты с госучастием). Сюда стекаются извещения, протоколы, контракты со **всех** 8 федеральных ЭТП. Для нашей тематики это 80–90 % всего релевантного объёма (стройка, муниципалитеты, дорожники — основные покупатели бетона).

> ⚠️ **Важное изменение 2025:** с **1 января 2025 года публичный FTP-сервер `ftp.zakupki.gov.ru` закрыт.** Раньше можно было свободно качать XML-архивы извещений/контрактов — теперь нельзя. Это меняет всю схему парсинга (см. раздел 4).

Что осталось доступным:
- **Веб-сервис интеграции** (`int44.zakupki.gov.ru/eis-integration/...`, методы семейства `getDocs`/`getPublicDocs`). С 2025 требует **токен/индивидуальное информирование** через личный кабинет ЕИС либо запросы, подписанные **КЭП** (КриптоПро). Раньше работал анонимно — теперь нет.
- **Раздел «Открытые данные»** (`zakupki.gov.ru/epz/opendata/`) — паспорта наборов данных (реестр недобросовестных поставщиков, справочники и пр.). Полезен для справочников и обогащения, но не для полной выгрузки извещений.
- **Публичный поиск на сайте** — для парсинга через headless-браузер (хрупко, есть капча/лимиты, юридически — серая зона).

### Уровень 2. Электронные торговые площадки (ЭТП)

**8 федеральных ЭТП для 44-ФЗ** (на них проходят сами процедуры; данные дублируются в ЕИС):

1. **Сбербанк-АСТ** — `sberbank-ast.ru`
2. **РТС-тендер** — `rts-tender.ru`
3. **Росэлторг (ЕЭТП)** — `roseltorg.ru`
4. **ТЭК-Торг** — `tektorg.ru`
5. **ЭТП ГПБ (Газпромбанк)** — `etpgpb.ru`
6. **Российский аукционный дом (РАД)** — `lot-online.ru`
7. **АГЗ РТ / ZakazRF** (Татарстан) — `zakazrf.ru`
8. **Электронная торговая площадка «ЭТС»** — `etp-ets.ru`

**Коммерческие площадки и 223-ФЗ** (часть лотов сюда не попадает в ЕИС или появляется с задержкой — здесь много частных стройзаказчиков, которым нужен бетон):

- **B2B-Center** — `b2b-center.ru` (крупнейшая коммерческая, много стройки)
- **Fabrikant** — `fabrikant.ru`
- **OTC.ru** — `otc.ru`
- **Коммерческие секции** Росэлторг / ТЭК-Торг / ЭТП ГПБ

> Парсить каждую ЭТП по отдельности дорого и нестабильно. Делать это имеет смысл **только** для коммерческих площадок, чьи лоты НЕ дублируются в ЕИС (B2B-Center, Fabrikant, OTC) — там реальная добавочная ценность.

### Уровень 3. Агрегаторы (готовые API)

Коммерческие сервисы, которые уже собрали данные со всех ЭТП + ЕИС и отдают их через **API/выгрузки**. Это самый быстрый путь к результату — платим деньги вместо инженерных часов.

| Сервис | Доступ к данным | Заметки |
|--------|-----------------|---------|
| **Контур.Закупки** (СКБ Контур) | API, готовые интеграции (1С, Битрикс24) | Удобно для CRM, выгрузка по фильтрам |
| **Тендерплан** (`tenderplan.ru`) | **Открытый REST API** (`tenderplan.ru/api/doc/`, с 2021), интеграция с Битрикс24 | Хорошая документация, относительно недорого |
| **Seldon** (1.7 / Seldon API) | API «по заказам»: заказываешь просчёт фильтров → получаешь список | Самая полная база + аналитика, дороже |
| **Bicotender / Rostender / Synapse (synapsenet.ru)** | Поиск + выгрузки (Excel/API) | Synapse удобен для справки по ОКПД2 |

Форматы выгрузки у агрегаторов обычно: **API (REST/JSON), FTP, ТЕКОС, MS Excel**.

## 3. Сравнение вариантов: что выбрать

| Критерий | ЕИС напрямую | Парсинг ЭТП | Агрегатор (API) |
|----------|--------------|-------------|-----------------|
| Стоимость данных | бесплатно | бесплатно | подписка (₽/мес) |
| Стоимость разработки | 🔴 высокая (ЭЦП, токен, SOAP) | 🔴 очень высокая (8+ парсеров) | 🟢 низкая (1 API) |
| Полнота (44-ФЗ + 223-ФЗ) | 🟢 максимальная | 🟡 по площадкам | 🟢 максимальная |
| Коммерческие тендеры | 🔴 нет | 🟢 есть | 🟢 есть |
| Стабильность | 🟡 (изменения 2025) | 🔴 ломается при редизайне | 🟢 SLA |
| Скорость до результата | недели | месяцы | дни |
| Юридическая чистота | 🟢 официальный сервис | 🟡 серая зона (ToS) | 🟢 по договору |

## 4. Рекомендуемая архитектура парсинга

**Гибридная схема — быстрый старт через агрегатор, затем удешевление через прямой доступ к ЕИС.**

### Этап 1 (MVP, 1–2 недели): агрегатор по API
- Берём **Тендерплан** (открытый API + адекватная цена) или **Контур.Закупки**.
- Настраиваем фильтр: ОКПД2 из раздела 1 + ключевые слова + регионы поставки.
- Выгружаем в нашу БД/CRM: заказчик, объект закупки, НМЦК, сроки подачи, площадка, ссылка на лот, регион, объём (м³).
- ✅ Закрывает 100 % госзакупок и большинство коммерческих сразу.

### Этап 2 (оптимизация): прямой доступ к ЕИС
- Регистрируем личный кабинет ЕИС, получаем **КЭП** и настраиваем **индивидуальное информирование / токен** для веб-сервиса `getDocs`.
- Поднимаем загрузчик XML по 44-ФЗ/223-ФЗ → парсим в БД (XQuery/BaseX или Python + lxml).
- Снимаем зависимость от подписки на основной (государственный) объём.
- Агрегатор оставляем только под коммерческие площадки, если их данные ценны.

### Этап 3 (по необходимости): точечный парсинг коммерческих ЭТП
- Только B2B-Center / Fabrikant / OTC.ru, чьи лоты не видны в ЕИС.
- Через официальные API площадок, где они есть; иначе — headless-парсинг с соблюдением ToS.

### Модель данных (минимум полей на тендер)
```
tender_id, source (ЕИС/ЭТП/агрегатор), law (44/223/коммерч.),
customer_name, customer_inn, customer_region,
object_name, okpd2[], nmck (НМЦК), currency,
volume_m3, delivery_region, delivery_address,
publish_date, deadline_date, auction_date,
platform, url, status, documents[]
```

## 5. Юридические и технические замечания

- **44-ФЗ/223-ФЗ данные публичны** — их сбор и использование законны. Риски не в самих данных, а в **способе** доступа: массовый автоматический парсинг HTML-страниц может нарушать ToS площадки и упираться в антибот-защиту/капчу. Официальный веб-сервис ЕИС и API агрегаторов таких рисков не несут.
- **С 2025 для прямого доступа к ЕИС обязательна КЭП** (квалифицированная электронная подпись) и связка КриптоПро CSP + browser plug-in. Это организационный шаг, заложить время.
- **Дедупликация обязательна:** один лот виден и в ЕИС, и на ЭТП, и в агрегаторе. Ключ дедупа — реестровый номер закупки (ЕИС) + ИНН заказчика.
- **Частота обновления:** для тендеров на бетон критичны сроки подачи (часто 7–15 дней). Поллинг минимум 1–2 раза в сутки, лучше — несколько раз в день.

## 6. Итоговая рекомендация

1. **Старт — агрегатор по API (Тендерплан или Контур.Закупки)** + фильтры из раздела 1. Получаем поток релевантных тендеров за дни, без капексов на инфраструктуру.
2. **Параллельно — заводим КЭП и доступ к веб-сервису ЕИС** для прямой бесплатной выгрузки госзакупок (основной объём по бетону/ЖБИ).
3. **Точечно — коммерческие площадки** (B2B-Center, Fabrikant, OTC), если их уникальные лоты дают выручку.

> Главный вывод: **первоисточник — ЕИС (zakupki.gov.ru)**, но из-за закрытия FTP в 2025 прямой доступ усложнился (нужна КЭП/токен). Поэтому самый быстрый и надёжный старт — **агрегатор с готовым API**, а прямой доступ к ЕИС подключаем вторым шагом для удешевления.
